# نوديسك كلينك — NODISC Clinic

منصة ويب طبية تفاعلية متكاملة (ثنائية اللغة: **العربية RTL** و**الإنجليزية LTR**) لمركز **نوديسك كلينك** لجراحة المخ والأعصاب والعمود الفقري وعلاج الألم والتأهيل الحركي والصيدلية السريرية في صنعاء، تضم الموقع التعريفي، طلب المواعيد والحملات، المتجر الإلكتروني الطبي، ولوحة تحكم إدارية مترابطة.

---

## نظرة عامة على المشروع

يغطي التطبيق مسار المريض والعميل بالكامل إلى جانب أدوات الإدارة والتشغيل اليومية في واجهة واحدة مبنية بـ **React + TypeScript + Vite + Tailwind CSS v4**:

- **الموقع الطبي التعريفي:** استعراض الأقسام التخصصية الأربعة، الملف المهني للطبيب الرئيسي والفريق الطبي، الخدمات التشخيصية والعلاجية، المكتبة الطبية التوعوية، الأخبار، وقصص النجاح مع تقييمات خاضعة للمراجعة.
- **حجوزات المواعيد والحملات المجانية:** نموذج حجز مرتبط بالأقسام والخدمات والأطباء مع محاكاة حالات التوفر ورسائل التأكيد، وصفحة مخصصة للحملات الطبية المجانية وحساب السعة المتبقية تلقائيًا.
- **متجر صيدلية نوديسك والعروض والدفع المحلي:** عرض كل مجموعة رئيسية بشكل مستقل مع تفرعاتها (التجميل والعناية الشخصية، الفيتامينات والمكملات لكبار السن والأطفال والنساء، العناية بالأم والطفل، المستلزمات الطبية والعمود الفقري، وأجهزة العلاج الطبيعي)، صفحة مخصصة للعروض والتخفيضات (`/store/offers`) مع بطاقات تفاعلية ونسبة الخصم وتاريخ الانتهاء، طلب الأدوية عبر الوصفة الطبية، وتجربة دفع متكاملة تدعم المحافظ والبنوك المحلية في اليمن.
- **لوحة التحكم الإدارية (`/admin`):** 16 شاشة إدارية مترابطة في الوقت الفعلي مع الموقع العام والمتجر، تشمل إدارة الصفحة الرئيسية والأقسام والأطباء والمحتوى، إدارة مجموعات المتجر وتفرعاتها، إدارة المنتجات والعروض والأسعار والمخزون، إدارة المحافظ الإلكترونية وشعاراتها المخصصة، ورفع الصور مباشرة داخل كافة النماذج.

### الأقسام التخصصية الأربعة
1. **نوديسك لجراحة المخ والأعصاب (`NODISC Neurosurgery`):** استشارات الانزلاق الغضروفي العنقي والقطني، تضيق القناة الشوكية، والجراحات المجهرية الدقيقة عبر 13 تخصصًا دقيقًا.
2. **نوديسك لعلاج الألم (`NODISC Pain`):** تقييم الآلام الحادة والمزمنة وبروتوكولات علاج الألم التداخلية وفق معايير **Mayo Clinic** دون جراحة مفتوحة.
3. **نوديسك للتأهيل والعلاج الطبيعي (`NODISC Rehabilitation`):** برامج العلاج الطبيعي وتأهيل ما بعد الجراحة وتقنية الشد الرقمي المحوسب للعمود الفقري.
4. **نوديسك للصيدلية (`NODISC Pharmacy`):** صرف الوصفات العصبية والألمية، ومنتجات التجميل والفيتامينات والأم والطفل ودعامات العمود الفقري وأجهزة TENS المنزلية.

## وسائل الدفع الإلكتروني وتجربة السلة

يدعم المتجر في صفحة إتمام الطلب (`/store/checkout`) وتذييل الموقع ثلاث طرق مرنة مع عرض العملات (`YER` / `SAR` / `USD`):

- **الدفع نقدًا عند الاستلام** أو الدفع مباشرة في صيدلية المركز عند الاستلام المباشر.
- **الدفع الإلكتروني عبر الشبكات والمحافظ المحلية (مع إمكانية إضافة محافظ وشعارات مخصصة من لوحة التحكم):**
  - **الكريمي حاسب** — بنك الكريمي الإسلامي (`784545908`)
  - **محفظة جوالي (Jawali)** — كاك بنك (`772070207`)
  - **محفظة جيب (Jeeb)** — بنك التضامن (`772070207`)
  - **محفظة ون كاش (OneCash)** (`772070207`)
  - **محفظة فلوسك (Flousak)** — بنك اليمن والكويت (`772070207`)
- **مزايا صفحة الدفع والإيصال:**
  - بطاقات تفاعلية لاختيار المحفظة مع زر نسخ رقم الحساب/المحفظة بنقرة واحدة وعرض شعار المحفظة.
  - حقول إدخال رقم المرجع/الحوالة، اسم المحوّل، وإرفاق صورة إشعار التحويل (مع خيار تأكيد الإشعار عبر واتساب).
  - دعم **تقسيم الدفع على وسيلتين** (مثل عربون إلكتروني + الباقي عند الاستلام) مع موازنة تلقائية للمبلغ المتبقي.
  - شريط متابعة حد التوصيل المجاني، صفحة إيصال قابلة للطباعة، وزر إرسال تفاصيل الطلب مباشرة إلى واتساب الصيدلية.

## لوحة التحكم الإدارية والأدوار التجريبية

يمكن الوصول إلى لوحة التحكم عبر المسار `/admin` أو `/admin/login` والتبديل بين 5 أدوار بصلاحيات محددة:

| الدور | المعرّف | الصلاحيات الأساسية |
| :--- | :--- | :--- |
| **مدير النظام** | `admin` | صلاحيات كاملة على جميع الأقسام، المستخدمين، الصلاحيات، والإعدادات |
| **محرر المحتوى** | `editor` | إدارة الصفحة الرئيسية، الأقسام، الأطباء، الخدمات، المكتبة، الأخبار، وقصص النجاح |
| **موظف الاستقبال** | `reception` | إدارة طلبات المواعيد، جدول الدوام والإجازات، سجل SMS، والحملات الطبية |
| **مسؤول المتجر والصيدلية** | `store_manager` | إدارة هيكل المتجر، المنتجات والأسعار، المخزون، الطلبات والتحصيل، والوصفات |
| **مستخدم تقارير** | `reports_viewer` | عرض لوحة النظرة العامة وتقارير الأداء والطلبات والحجوزات |

## التشغيل والتطوير محليًا

### 1. المتطلبات
- **Node.js** `18+` (أو `20+` الموصى به)
- **npm** أو **bun**

### 2. تثبيت الحزم وتشغيل بيئة التطوير
```bash
npm install
npm run dev
```
يعمل خادم التطوير محليًا على المنفذ الافتراضي `3000`:
`http://localhost:3000`

### 3. التحقق من الأنواع والبناء للإنتاج
```bash
# فحص الأنواع باستخدام TypeScript
npm run lint

# بناء نسخة الإنتاج في مجلد dist/
npm run build

# معاينة نسخة الإنتاج محليًا
npm run preview
```

## ملاحظة نطاق البيانات والتكامل المستقبلي

يعمل المشروع حاليًا كتطبيق **Frontend** متكامل يعتمد على حالة الجلسة و`localStorage` (للسلة واللغة والعملة) لتجربة ومحاكاة كافة سيناريوهات الحجز والدفع والوصفات ولوحة التحكم فورًا دون الحاجة إلى خادم خلفي. تم تنظيم البيانات والأنواع (`src/types/clinic.ts` و`src/config/siteConfig.ts` و`src/context/DataStoreContext.tsx`) لتسهيل ربطها مستقبلاً بواجهات API وقواعد بيانات حقيقية وبوابات الدفع الرسمية.
